쇼피 K뷰티 소싱 플랫폼 — 처음 쓰는 분을 위한 안내서
이 플랫폼은 뭐예요?

한국 올리브영에서 잘 팔리는 화장품을 매일 자동으로 모아, 쇼피(동남아)에 팔면 남는지(마진)를 계산해 GO / 검토 / 제외로 골라주는 도구입니다. 골라준 상품의 광고 콘텐츠(상세·썸네일·영상)까지 만들 수 있어요. 한마디로 "뭘 떼다 팔지"를 정해주는 두뇌입니다.

① 화면 구조

상단 탭 = 팀(역할)별 화면: 관리자·소싱담당·세일즈담당·마케팅담당·물류담당·디자인담당·회계담당.
왼쪽 메뉴 = 기능 그룹: 오늘(팀 브리핑) · 분석(시장현황·소싱타이밍·TOP상품·경쟁구도·추적) · 운영(수익 시뮬·SKU·프로모션) · 성장(KPI·로드맵) · 콘텐츠(상세·바우처) · 도구(배송계산·콘텐츠 생성기·마진검증).

② 꼭 알아야 할 5가지 개념 (입문자용)

1) 3중 수수료 — 쇼피에 팔면 떼이는 돈(판매+거래+인출0.9%). 나라마다: 베트남 19.55% · 싱가포르 18.55% · 필리핀 8.66% · 대만 10.50% · 브라질 20%.

2) EMS 배송비 — 한국→해외 우체국 배송. 무게로 결정(≤100g 10,800원 ~ >500g 23,000원). 가벼울수록 유리.

3) 권장가 — 목표 마진(약 25%)이 남는 추천 판매가. 총원가 ÷ (1 − 수수료 − 0.009 − 0.25), 총원가=매입가+EMS.

4) 개당 분할 — 1+1·10매 묶음은 낱개로 쪼개 계산하면 배송비 부담↓ 마진↑. 우리 표는 이 방식.

5) 직입점 제외 — 한국 브랜드가 현지에 직접 공식 판매 중(메디힐·코스알엑스·라운드랩·클리오·바이오던스·달바·티르티르 등)이면 가격경쟁이 안 돼 제외.

③ 판정 색깔의 뜻
GO 마진 충분 → 바로 등록 검토
검토 마진 경계(24%대) → 등록가·바우처 조정 시 GO 가능
제외 직입점/글로벌 공식유통 → 진입 부적합
NO 마진 안 나옴 → 패스
④ 매일 이렇게 (핵심 흐름)
1. 매일 09:30 올리브영 베스트 자동 수집·분석.
2. 분석 > TOP 상품에서 오늘 TOP10·판정 확인.
3. GO 배지 클릭 → 콘텐츠 생성기 자동 이동 + 상품 입력 + 생성.
4. 상세·카피 검토(현지어 검수) → 등록 진행.
5. 아래 SG 매칭으로 싱가포르 경쟁 상황 확인.

📊 시장 현황 — 마켓별 트렌드·성장률.

① 소싱 타이밍 — 올영 세일 기준 매수 타이밍.

🏆 TOP 상품 — 핵심. 올영 TOP10 마진·권장가·판정 + SG 매칭.

🔍 경쟁 구도 — 동일 상품 경쟁 셀러 비교.

🎯 추적 대시보드 — 등록 상품·추격 상황 추적.

💰 수익 시뮬레이터 — 가격·수량 → 예상 순이익.

📦 SKU 파이프라인 — 소싱→등록→판매 단계 관리.

📅 프로모션 캘린더 — 메가세일 일정·광고 타이밍.

📈 KPI 벤치마크 — 목표 대비 성과.

🛣️ 성장 로드맵 — 단계별 확장 계획.

🎟️ 바우처 전략 — 첫구매·묶음·리뷰 쿠폰 설계.

🚚 배송 비교 계산기 — EMS vs 타 배송사 비용.

🎨 콘텐츠 생성기 — URL/상품명 → 상품명·카루셀·상세·틱톡·바우처 자동. (GO 클릭 시 자동 연결)

🌏 전체 마켓 시뮬레이터 — 여러 나라 동시 마진 비교.

✅ 실시간 마진 검증 — 매입가·무게 입력해 즉시 마진 확인.

⑥ 팀 화면(상단 탭) & AI 에이전트

상단 탭에서 역할별 화면을 열고, "○○에게 물어보기" 버튼으로 분야별 AI(소싱·세일즈·마케팅·물류·디자인·회계)에게 바로 질문하세요. 예: 마케팅 → 카피·릴스, 물류 → 배송비, 회계 → 손익.

⑦ 주의사항
· 숫자는 추정치 — 등록 전 최신 수수료·무게로 재확인.
· 제외 브랜드는 떼다 팔지 않기(직입점/공식유통).
· 현지어 카피는 자동번역 그대로 금지, 검수 후 사용.
· 우상단 날짜가 오늘인지 확인(매일 갱신).
문의: 팀장 신진우 · 플랫폼 업데이트에 따라 갱신됩니다.
